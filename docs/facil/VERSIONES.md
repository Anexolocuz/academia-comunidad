# 🏷️ Versiones — versión fácil

> Todo el detalle: [manual completo](../VERSIONES.md)

- Cada versión tiene un número, por ejemplo **1.0.0**. Lo ves en Ajustes → Avanzado → Esta instalación.
- Lo nuevo de cada versión está en [CHANGELOG.md](../../CHANGELOG.md).
- El código, el instalador, la imagen de Docker y el ZIP **siempre tienen el mismo número**.

## Actualizar

| Si instalaste con… | Haz esto |
|---|---|
| El instalador + Git | Ajustes → Avanzado → **⬇️ Actualizar ahora** |
| Docker | `docker compose pull && docker compose up -d` |
| ZIP | Baja el ZIP nuevo y copia tu carpeta `datos/` dentro |

**Tus datos nunca se borran al actualizar.**
