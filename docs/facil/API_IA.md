# ☁️ API de IA — versión fácil

> Todo el detalle: [manual completo](../API_IA.md)

**¿Para qué?** Para que las lecciones salgan **más rápido** (y, con un modelo mayor, a veces mejores). **No es necesaria**: la IA de tu PC basta.

**Apagada por defecto.** Si no la enciendes, nada sale de tu PC.

## Para conectarla (quien administra)
1. ⚙️ Ajustes → **🔔 Modo corto, avisos y ☁️ API** → 🛠️ Administración.
2. Elige tu proveedor (Anthropic, OpenAI, Gemini, OpenRouter, Groq, DeepSeek, Mistral… o «Otro»).
3. Pulsa el enlace, crea tu **clave** y pégala.
4. **📋 Ver modelos** → elige uno. Pon los **precios** y un **tope al mes**.
5. **🔌 Probar** → **💾 Guardar** → marca «Permitir la API».

## Para usarla (cada persona)
- Marca **«Usar la API en mi cuenta»**, elige para qué tareas y tu **tope al mes**.
- Tu **nombre nunca sale**. Tus metas, solo si lo marcas.
- **Nunca salen**: el tutor, tus apuntes y fotos, tus entregas, tus ideas ni tu cartera.

## Si algo falla
La tarea sigue sola en tu IA local. Nada se pierde.
