# 🚀 Inicio rápido (5 minutos)

> Versión fácil. Todo el detalle: [INSTALACION completa](../INSTALACION.md)

**Necesitas:** un PC tuyo (Windows, Mac o Linux). La Academia y tus datos se quedan en **tu** PC.

## 1. Instala una IA (una sola vez)

1. Descarga **Ollama**: https://ollama.com/download e instálalo.
2. Abre una terminal y escribe: `ollama pull gemma3:4b`
   (si tu PC tiene 16 GB de RAM o más, mejor `gemma3:12b`).

## 2. Descarga la Academia

- Ve a https://github.com/Anexolocuz/academia-comunidad → **Releases** → baja el `.zip` y descomprímelo.
- (O, si usas Git: `git clone https://github.com/Anexolocuz/academia-comunidad.git academia`)

## 3. Instálala

| Tu sistema | Haz esto |
|---|---|
| Windows | doble clic en **INSTALAR.bat** |
| Mac | doble clic en **Instalar.command** (la 1.ª vez: clic derecho → Abrir) |
| Linux | en la carpeta: `./instalar.sh` |

Cuando pregunte **«¿Escanear este PC ahora?»** responde **s**. Te dirá qué encontró.
Cuando pregunte **«¿Aplicar esta configuración?»** responde **s**. Lo demás: Enter.

## 4. Úsala

Se abre sola en **http://127.0.0.1:8092**.

1. ⚙️ **Ajustes** → escribe quién eres y qué quieres aprender → sube la prioridad de 1-2 áreas → **Guardar**.
2. ☀️ **Hoy** → empieza tu primera lección.
