# 🎨 Apariencia — versión fácil

> Todo el detalle (y cómo crear tus propios colores): [manual completo](../APARIENCIA.md)

**⚙️ Ajustes → 🎨 Apariencia:**

1. **Modo:** Automático, Claro u Oscuro.
2. **Paleta:** Clásica, Bosque, Océano, Atardecer, Sepia (para leer mucho) o Alto contraste.
3. **Color de acento:** elige el que quieras.
4. **Tamaño de letra:** de Pequeña a Muy grande.

Se guarda en cada navegador: el celular y el PC pueden verse distinto.
